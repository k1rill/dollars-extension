Проверка расширения

Откройте эту страницу через локальный сервер (не file://), например из папки extension: 

python3 -m http.server 8765

Затем в браузере: http://127.0.0.1:8765/test-page.html

В манифесте должны быть совпадения для http://127.0.0.1/*.
