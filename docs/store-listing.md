# Публикация в Chrome Web Store — тексты (русский)

## Краткое описание (до ~132 символов)

Используйте одну строку в карточке расширения:

`Цены av.by, Onliner и 21vek.by в USD и EUR (НБ РБ). Подсказка и подпись рядом с ценой.`

*(Проверьте длину в форме: лимит Chrome Web Store для короткого описания — обычно 132 символа.)*

---

## Полное описание (страница расширения в магазине)

**Ў далярах** показывает эквивалент цены в **долларах США и евро** на **av.by** и поддоменах (**cars.av.by**, **moto.av.by** и др.), в каталоге **catalog.onliner.by** и на **21vek.by**.

**Возможности:**

- Официальные курсы **Национального банка Республики Беларусь** (ежедневные данные через публичный API НБ РБ).
- **Всплывающая подсказка** и/или **подпись рядом с ценой** «≈ $… · €…»; можно показывать только USD, только EUR или обе валюты.
- Включение по **сайтам**: все поддерживаемые сразу или выборочно (av.by, Onliner, 21vek).
- Цены в BYN: **«51 211 р.»**, **«2390,00 ƃ»**, **«1 167,29 р.»** — в том числе при разбитой вёрстке на странице.

**Конфиденциальность:** регистрация не нужна. Настройки и кэш курсов хранятся **только на вашем компьютере** в браузере (локально). Расширение не собирает персональные данные на отдельный сервер разработчика.

Подходит покупателям на белорусских площадках, которым удобно ориентироваться в долларе и евро.

## Скриншоты (рекомендации Chrome Web Store)

Размер **1280×800** или **640×400**, формат PNG или JPEG:

1. Список объявлений на `cars.av.by` с видимой подписью конвертации рядом с ценой.
2. Всплывающая подсказка над ценой (USD, EUR, сумма в рублях).
3. Окно расширения (popup): курсы НБ РБ и галочки настроек.

Подписи к скриншотам на русском помогают модерации (необязательно, но желательно).

## Анкета «Конфиденциальность» в консоли разработчика

Кратко для формы:

- **Личные данные пользователей:** не собираются и не передаются разработчику; отдельного бэкенда у расширения нет.
- **Локальное хранилище:** только настройки отображения и кэш курсов (`chrome.storage.local`).
- **Сетевые запросы:** к **api.nbrb.by** (курсы валют) и работа скриптов на **av.by**, **catalog.onliner.by** и **21vek.by** (конвертация на открытых страницах).

**Политика конфиденциальности:** опубликуйте файл **[docs/PRIVACY_POLICY.md](PRIVACY_POLICY.md)** (например, через GitHub Raw) и укажите публичную ссылку в форме загрузки.
